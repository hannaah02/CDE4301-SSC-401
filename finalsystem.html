Final system design

Introduction

The layout of the hotel is approximated below with the viable area for implementation being 1288m2 of 0.5hectares land area, using hotel widths as reference. [1]

The final CSP system consist of modular ‘system of rigs’ where each system consists of multiple rigs (receiver and reflectors only, each rig is 1x1m) connected to a TES tank. (see figure XX) This aims to reduce overall cost per rig.

Water is supplied to the TES tank via the water mains, which also provides pressure driving flow to the hot water storage tank and showers. The hot water storage tank is located in the hotel where it serves as a storage location for extra hot water and provides additional heating to maintain water temperatures.



Thermal transmission

The layout for the system of rigs for each system size (number of rigs in a system) is shown below, and is selected to minimise distance between each rig and TES while allowing for modular expansion.

As the system will be pressurised due to the connections to the water mains, the existing fixtures and pipes needs to be altered to fit the new conditions.

  1. The rubber hose will be switched to 304 stainless steel pipe, as it is used in water mains connections, is durable outdoors, and can withstand high temperatures [4][5]
  2. Clamps needs to be changed to relevant fittings
  3. Pressure relief valve added for safety
  4. Non-return valve to prevent backflow

Furthermore, two configurations to connect the receivers to the TES are considered:

  1. Parallel configuration, where each reciver is connected independantly to the TES
  2. Series configuration, where fluid flows sequentially through multiple rigs

We also need to consider the system head, which is affected by the pipe size. Hence, these 3 pipe sizes are considered for the pipes:

  1. 1/8" nominal pipe, smallest common size [6]
  2. 3/4" nominal pipe, commonly used in residential plumbing [7]
  3. 1" nominal pipe, commonly used in residential plumbing [7]

Finally, the optimal system size for the system of rigs has to be determined.

Pipe size

To determine the optimal pipe size, the system head required is compared for the different pipe size. The larger the system head, the more resistance exists in the system that the pump has to overcome, leading to a more powerful pump required. Thus, system head for each system size is used to compare the pipe sizes, considering both parallel and series configuration.

Between the 1/8" and 3/4", there is a large difference in system head in both parallel and series configuration. The extremely large head for 1/8" pipe, especially in the series configuration, with head 1167.41m for 10 rigs, makes it unsuitable for the system. Between 3/4" and 1", 1" have lower system head overall but the difference is minimal (see below). However, with increased pipe size, the heat loss increases. Considering aerogel insulation for 304 stainless steel pipe with commonly used sizing for 3/4" and 1", to reduce limit heat loss to 7.1150W along 3m (5% loss of 142.3W), the thickness of insulation needs to change from XX mm (3/4") to XX mm (1"). The total thickness needs to be minimal, with maximum diameter of 7cm based on experience with our prototype rig. Hence, 3/4" pipe is selected.

Parallel vs series configuration

To decide the optimal configuration, the thermal efficiency of the pipes within the system of rigs will be considered. The length of the pipe is determined from:

  1. Layout of rigs (see figure XX and XX above)
  2. Pipe length estimation (to run loop in MATLAB, see Appendix XX)

Aircon insulation is used as the insulation, based on tests conducted and implementation (see sections above). Using the highest possible temperature different in the system of 35ºC, 25mm of aircon insulation is used which is a commonly available thickness (thickest available) that provides heat loss per meter of 7.1722W/m. [8] This meets the design requirements of heat loss per meter of ≤7.95W/m.

Based on these, the thermal efficiency for each system size (no of rigs) for both parallel and series system configuration is plotted.

Based on the results, the parallel configuration is less efficient with increased system size and the series configuration shows the opposite trend. This is caused by the reduction in the average length of pipe per rig with increasing system size in the series configuration, allowing the average heat loss per rig to fall, in comparison to the parallel configuration where the average length of pipe per rig increases with increasing system size. Hence, series configuration is the optimal choice with less heat loss.

Optimal system size

The optimal system size will be calculated based on the maximum system of rigs able to fit on the available space.

Based on the area available in the hotel (0.5 hectares) we can get the approximate layout of the building (see below). For this analysis, we will look at one side of the hotel (same on both sides).

Based on the dimensions, we can estimate the maximum number of system of rigs that fits on one rooftop and its layout for the different system size (see below for example and Appendix XX for all).

Based on the layout, the pipe loss of the system can be obtained, assuming maximum number of system of rigs are used for each system size. The pipe loss versus system size is below.

To meet the design specifications of pipe losses ≤17.5%, the system size should be over 3.

To accurately assess the potential of the system, the total useful energy for these configurations is considered to better assess the performance of the system. Not all system size allows the full usage of the rooftop area (see system size 7 versus 4 below) and the useful energy comparison is a more accurate comparison as to the potential of the system.

The total useful energy obtained is oberved to peak at system size of 4 and 6, with system size 6 having 737.7W less than system size of 4, being a 0.9105% reduction in useful energy. These system sizes are ideal since they have a neater square/rectangular shape overall, making it more efficient for modularity and being able to make full use of spaces which tend to be rectangular. It is also small enough to ensure that more systems will be able to fit, being less constrained by larger widths. Between these 2 configurations, cost analysis will be used to finalise the optimal size.

Cost analysis

The equipment required for the entire setup (both rooftops) follows the diagram below and the rig layout used earlier (see figure XX).

Using cost of purchasing in bulk, the overall cost of the system for the thermal transmission subsystem is calculated for system of rigs size of 4 and 6 as below.

Per system, the system size of 6 is cheaper by SGD$4.67, but when considering a per rig cost (instead of per system of rigs), the system size of 4 costs $68.98 while system size of 6 costs $46.77 (32.20% reduction in cost). This reduction is the result of having the pump cost (most expensive item in the system for thermal transmission) distributed over more rigs.

Looking at the overall system, system size of 6 is cheaper by SGD$29,971.51 (33.39% reduction in cost) for installation on both roofs, which is largely due to the lower number of system of rigs required for system size 6 than system size 4 and overall the lower cost per rig of system size of 6.

Hence, considering the costs, system size of 6 is the optimal choice as although it provides less useful energy (by 0.9105%), it is minimal compared to the cost reductions (of 33.39%).

In this final system size of 6, the total power required per rig is 15W assuming maximum power of 90W is used [13: pump], meeting the design requirements of 136.96W per rig.
